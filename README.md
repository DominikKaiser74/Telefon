Konfiguration für die Wildix Telefonanlage um für jeden Tag in einem Turnus von 19 Tagen unterschiedliche Ansagetexte nach Dienstschluss abzuspielen.
Feiertag = 0 wie ein Sonntag
Feiertag = 1 Feiertag fällt auf einen Wochentag Start des Nachtdienst um 8 Uhr 
Feiertag = 2 24 und 31 Dezember sind Halbe Feiertage Nachtdienst beginnt um 12 Uhr

Feiertage werden von data.gv.at als CSV für Österreich geladen

Als Datenbank wird mariadb verwendet
config.py File nach Gegebenheiten anpassen
